# Ruedly — App Móvil

Aplicación móvil de Ruedly. Reutilizará el motor de recomendación de ruedas
(compartido con `../frontend` o consumido desde `../backend`) ofreciendo la
misma experiencia en dispositivos iOS y Android.

## Estado

app móvil. Define aquí el stack elegido (por ejemplo React Native con Expo,
Flutter, etc.) y añade su gestión de dependencias correspondiente.
